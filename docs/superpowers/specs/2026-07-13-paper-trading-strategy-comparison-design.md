# 模拟盘策略比较设计

## 背景与目标

模拟盘当前将投资组合配置、策略选择、单次回测、稳健性测试、结果详情和历史记录放在同一个长页面中。新的设计不删除或改变这些能力，而是将整个现有界面收纳为默认的“历史回测”Tab，并增加独立的“策略比较”Tab。

策略比较只回答一个问题：在完全一致的数据区间、资金、成本和指标口径下，防守型个股动量是否比简单基准提供了可重复的风险调整收益。第一版固定比较以下三种策略：

1. SPY 买入持有。
2. SPY / 现金 200 日均线轮动。
3. 防守型个股动量 Strategy V0。

该功能是研究与淘汰工具，不承诺盈利，也不通过开放大量参数鼓励调参。

## 页面信息架构

模拟盘页面顶部显示两个一级 Tab：

1. `历史回测`：默认选中，包含当前模拟盘的全部现有界面和行为。
2. `策略比较`：运行并展示统一的三策略比较。

刷新页面后始终回到“历史回测”，不持久化上次选择。切换 Tab 不清除当前会话中已经加载的历史回测或策略比较结果。

`PaperTrading.tsx` 继续作为页面入口和 Tab 容器。当前页面主体保留在历史回测条件区域；新的比较界面放入独立的 `StrategyComparisonTab`，避免继续扩大现有页面文件的职责。

## 比较参数

第一版只允许用户设置：

- 开始日期。
- 结束日期。
- 初始资金，默认 100,000 美元。
- 单边交易成本，默认 20 bps。

默认结束日期是今天，默认开始日期是今天往前五年。提供 1 年、3 年、5 年和 10 年快捷范围，同时保留自定义日期。回测区间少于一年时不允许运行。

后端必须在所选开始日期之前额外读取至少 252 个交易日的数据作为预热。净值、收益和指标仍从用户选择的开始日期计算，预热期不能计入结果。

第一版不建立命名历史事件目录。“历史事件段”由同一组开始和结束日期表达；疫情暴跌、加息熊市等命名快捷区间属于后续范围。

## 统一执行规则

三个策略必须使用：

- 相同初始资金。
- 相同开始和结束日期。
- 相同单边交易成本。
- 相同复权价格口径。
- 相同交易日序列。
- 收盘后生成信号、下一交易日开盘成交的执行约束。
- 现金收益率 0% 的保守假设。

页面必须明确展示现金收益率假设。第一版不引入短期利率数据或股息税模型。

## 策略定义

### SPY 买入持有

在回测开始后的第一个可成交日买入 SPY，扣除交易成本后持有至回测结束。结束时为统一统计可以按最终价格估值，不强制产生额外卖出交易。

### SPY / 现金 200 日均线轮动

每日收盘后比较 SPY 收盘价与其 200 日简单移动平均线：

- 收盘价高于 200 日均线时，目标仓位为 100% SPY。
- 收盘价低于或等于 200 日均线时，目标仓位为 100% 现金。

状态变化后的下一交易日开盘调仓并扣除交易成本。现金收益率为 0%。

### 防守型个股动量 Strategy V0

每个换仓日从美股候选面板中筛选：

- 过去 60 个交易日平均成交额排名最高的 200 只股票。
- 当前价格高于 5 美元。
- 至少有 252 个交易日历史。
- 当前收盘价高于自己的 200 日简单移动平均线。

主信号固定为 12-1 动量：

```text
momentum = close[t-21] / close[t-252] - 1
```

在符合条件的股票中选择动量最高的 15 只。每周最后一个交易日收盘后计算信号，并在下一交易日开盘调仓。

股票使用过去 20 日实现波动率的倒数分配权重，单只股票目标权重不得超过组合净值的 8%。不使用杠杆；因权重上限、数据缺失或股票不足产生的剩余资金保留为现金。

Strategy V0 使用 SPY 的 200 日均线作为市场状态：

- SPY 高于 200 日均线：股票总目标仓位 90%，现金至少 10%。
- SPY 低于或等于 200 日均线：股票总目标仓位 30%，现金至少 70%。

第一版不加入指数 ETF 做空对冲。主动现金管理必须先被单独验证，避免无法区分收益和风险改善来自选股、现金还是对冲。

## 股票池偏差与可信度

项目现有 `sp500` 面板使用 2026-05-17 获取的当前 S&P 500 成分股名单，不提供历史时点成分股，因此 Strategy V0 第一版存在幸存者偏差。后端可以在该候选面板内按历史成交额动态选择前 200 只，但不能将结果描述为无偏历史验证。

API 必须返回：

```json
{
  "survivorship_bias": true,
  "universe_source_date": "2026-05-17"
}
```

页面必须持续显示黄色提示：

> Strategy V0 使用 2026-05-17 获取的当前 S&P 500 成分股回测历史，存在幸存者偏差。结果仅用于策略结构筛选，不能作为实盘盈利证据。

当 `survivorship_bias` 为真时，Scorecard 最高只能显示“初步通过”，不能显示正式 `PASS`。未来接入历史成分股数据时，通过替换 Universe Provider 消除该限制，不重写策略逻辑。

## 后端架构与生命周期

新增异步策略比较资源：

```text
POST /paper-trading/strategy-comparisons
GET  /paper-trading/strategy-comparisons/{run_id}
```

创建请求包含：

```json
{
  "start_date": "2021-07-13",
  "end_date": "2026-07-13",
  "initial_capital": 100000,
  "cost_bps": 20
}
```

POST 返回待执行或已命中缓存的 comparison run。前端轮询 GET，直到状态为 `completed`、`partial` 或 `failed`。

后端比较服务负责：

1. 验证日期、资金和成本。
2. 加载 SPY 和美股面板，包括预热期。
3. 在相同交易日网格上运行三个策略。
4. 生成统一净值、回撤、仓位和指标。
5. 保存规则版本、数据来源、覆盖率和警告。
6. 按输入参数、策略版本和数据版本生成缓存键。

相同参数、策略规则版本和有效数据版本可以复用本地缓存。策略实现与 API 编排分离，纯策略函数不进行网络或文件 I/O。

## 返回数据

每个策略结果包含：

- 状态和失败原因。
- 每日归一化净值。
- 每日回撤。
- 每日股票仓位和现金比例。
- 分年度收益。
- 累计收益。
- CAGR。
- Sharpe。
- 最大回撤。
- Calmar。
- 年化波动率。
- 最差年度。
- 月度胜率。
- 换手率。
- 交易成本总额。
- 平均和最低现金比例。
- 数据覆盖率。

比较结果还包含策略规则版本、数据截止日期、成分股来源日期、幸存者偏差标记和统一方法说明。

## 前端展示

策略比较 Tab 按以下顺序展示：

1. 日期、资金和成本表单。
2. “运行统一比较”按钮。
3. 异步进度、缓存状态和数据覆盖提示。
4. 三个策略的核心指标卡。
5. 三条归一化净值曲线。
6. 三条水下回撤曲线。
7. 现金比例或市场暴露曲线。
8. 分年度收益柱状图或表格。
9. Scorecard 和方法说明。

指标卡至少显示累计收益、CAGR、Sharpe、最大回撤、Calmar 和年化波动率。图表必须与指标共用同一条后端净值序列，前端不得重新计算另一套收益口径。

Scorecard 检查：

- 最大回撤是否不超过 12%。
- Sharpe 是否不低于 0.8。
- 风险调整收益是否超过 SPY / 现金轮动。
- 扣除交易成本后收益是否为正。
- 数据覆盖是否满足计算要求。
- 是否存在幸存者偏差。

页面不以总收益最高为依据宣布“最佳策略”，只显示各项门槛的通过、未通过或无法判断。

## 失败和部分结果

- SPY 数据失败：整个比较任务失败。
- Strategy V0 股票数据覆盖不足：保留两个 SPY 策略结果，任务状态为 `partial`。
- 某日有效股票少于 15 只：使用可用股票并把剩余目标仓位留在现金中。
- 指标预热数据不足：对应策略不可用，不以零值代替。
- 某个策略计算失败：保留其他策略结果和具体错误原因。
- 数据缺口：返回覆盖率和警告，不进行静默填零。
- 页面离开或 Tab 切换：后台任务继续，返回比较 Tab 后可以恢复轮询。

## 测试策略

前端测试覆盖：

- 模拟盘默认显示“历史回测”。
- 两个 Tab 的顺序和可访问名称正确。
- 当前历史回测内容与主要操作仍然可用。
- 比较表单默认过去五年至今天。
- 异步任务的 pending、completed、partial 和 failed 状态。
- 幸存者偏差、数据缺口和方法说明持续可见。
- 三类图表和指标使用 API 返回的统一序列。

后端单元测试覆盖：

- 200 日均线轮动状态变化只能在下一交易日执行。
- 12-1 动量不读取未来数据。
- 周频调仓、前 15 名选择、波动率倒数权重和 8% 上限。
- SPY 状态下 90% / 30% 股票仓位和剩余现金。
- 成本从每次仓位变化中扣除。
- 预热期不计入回测收益。
- 三个策略交易日和初始资本一致。
- 指标由同一净值序列生成。
- 缓存键包含参数、策略版本和数据版本。
- 部分股票失败时返回覆盖率并保留可用结果。

API 测试覆盖创建、轮询、缓存命中、参数错误、部分成功和全部失败。

## 第一版范围边界

第一版不包括：

- 历史时点 S&P 500 成分股数据采购或抓取。
- ETF 做空对冲。
- 港股 Strategy V0。
- 现金利息或税费模型。
- 命名历史事件目录。
- Strategy V0 参数编辑器。
- 自动搜索最优参数。
- 根据最高收益自动推荐策略。

这些限制用于保持第一版可验证、可解释，并避免再次扩大功能范围。
