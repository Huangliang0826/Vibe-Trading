# 多时间段测试自动运行赢家回测

## 目标

用户点击模拟盘的“多时间段测试”后，系统完成稳健策略筛选，并自动运行排名第一的策略，无需再次点击“运行回测”。

## 流程

- 多时间段测试继续使用当前组合、资金、结束日期、三年窗口和一年滚动步长。
- 筛选完成后保留稳健性矩阵，并把策略选择器切换到 `best_strategy`。
- 使用当前组合、开始日期、结束日期、初始资金及赢家策略的当前参数创建普通模拟盘回测。
- 创建成功后沿用现有轮询流程，自动展示收益曲线、交易明细、策略总结和最新交易。
- 自动回测运行期间，“多时间段测试”和“运行回测”按钮保持禁用，避免重复提交。
- 若稳健筛选没有返回赢家，则只展示稳健结果，不创建回测，并显示可读错误。
- 若赢家回测创建或执行失败，保留稳健性矩阵和赢家选择，同时显示具体错误。

## 测试

- 前端测试验证赢家返回后会以赢家策略和当前表单参数创建一次回测。
- 验证无赢家时不创建回测。
- 验证自动创建失败时保留稳健结果并显示错误。
