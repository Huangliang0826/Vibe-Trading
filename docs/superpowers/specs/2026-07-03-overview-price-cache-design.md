# 总览价格走势图缓存

## 目标

总览页面刷新或重新进入时立即显示自选股价格走势图，避免所有股票同时等待外部行情源。

## 缓存规则

- 历史价格按 `market + code + period` 缓存在浏览器本地，TTL 为 24 小时。
- 实时报价按 `market + code` 缓存，TTL 为 60 秒。
- 缓存内容包含保存时间、历史 bars、股票名称及报价。
- 缓存未过期时直接显示，不发送重复请求。
- 缓存过期时先显示旧数据，再后台请求最新数据；更新成功后替换页面与缓存。
- 没有缓存时保持现有加载状态和错误提示。
- 切换走势图区间时使用对应区间的独立缓存，不混用 1Y、3Y、5Y 或 ALL 数据。
- 重大历史事件与普通价格图继续共享同一份历史行情缓存。

## 后端缓存

- 启用现有 `VIBE_TRADING_DATA_CACHE` 本地行情缓存，减少前端缓存失效后的外部抓取时间。
- 浏览器 API 仍保持 `no-store`，避免不可控的 HTTP 缓存；缓存时效由应用代码明确管理。

## 测试

- 验证缓存键按市场、代码和周期隔离。
- 验证 24 小时内历史数据和 60 秒内报价不会重复请求。
- 验证过期缓存立即显示并在后台刷新。
- 验证无缓存时仍正常请求并写入缓存。
