# 今日机会列表折叠设计

## 目标

总览的“今日机会”默认只展示当前筛选结果中的前三名，减少页面长度，同时保留查看完整排序的入口。

## 交互

- 结果不超过三只时，显示全部结果，不显示额外控制。
- 结果超过三只时，默认显示前三名，并显示“查看其余 N 只”按钮。
- 点击按钮后显示全部结果，按钮文案改为“收起”。
- 点击“收起”后恢复前三名。
- 市场、信号或机会等级改变时，列表自动恢复收起状态。
- 单只股票的详情展开逻辑保持不变。

## 实现与测试

前端在 `TodayOpportunities` 内维护列表展开状态，仅对 API 返回的已排序结果做显示切片，不改变后端排序和查询。组件测试覆盖默认前三名、展开全部、收起以及少于四只时不显示控制按钮。
