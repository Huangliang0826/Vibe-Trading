# 机会扫描多市场设计

## 目标

在“机会扫描”页面增加美股、A 股和港股市场切换，分别扫描标普 500、沪深 300和恒生科技成份股。每个市场拥有独立的最新结果、历史日期、排名变化、跟踪记录和质量统计。

## 产品行为

- 页面顶部使用分段控件切换 `美股`、`A股`、`港股`。
- 股票池固定映射为：美股 `sp500`、A 股 `csi300`、港股 `hstech`。
- 默认打开美股，切换后加载该股票池最近一次扫描。
- “更新”只运行当前市场，默认返回前 20 名。
- 首次没有结果时，可以直接在页面生成扫描。
- A 股缺少 `TUSHARE_TOKEN` 时显示后端原始可读错误，不影响其他市场。

## 数据隔离与兼容

- 扫描文件改为 `~/.vibe-trading/scans/{universe}/{asof}/run.json`。
- 跟踪文件改为 `~/.vibe-trading/tracking/{universe}/{asof}/tracking.json`。
- API 的最新、日期、历史、跟踪和校准接口都接受 `universe` 参数，并验证白名单。
- 现有 `~/.vibe-trading/scans/{asof}/run.json` 根据文件内的 `universe` 继续可读；新写入统一使用新目录。
- 旧跟踪记录无法可靠推断股票池时只作为 `sp500` 兼容数据读取，不移动或删除原文件。
- 同一日期不同市场不会覆盖。

## 前端数据流

1. 用户切换市场。
2. 页面请求该股票池的日期列表。
3. 有历史时加载最新一期及上一期；没有历史时展示生成按钮。
4. 用户点击更新，前端调用 `POST /scan/run?universe=...&top=20`。
5. 成功后刷新当前市场的结果、日期、跟踪和校准；失败时保留旧结果并显示错误。

## 测试

- 存储：同日三个股票池可并存，按股票池读取，旧目录兼容。
- API：股票池参数透传，非法股票池返回 400。
- 前端：市场切换加载正确股票池，更新只运行当前股票池，无历史时可首次生成。
- 构建：TypeScript 和 Vite 生产构建通过。

## 非目标

- 不提供自定义股票池。
- 不同时并行扫描三个市场。
- 不改变因子筛选算法或评分公式。
