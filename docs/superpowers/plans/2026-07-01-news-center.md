# 独立新闻中心 Implementation Plan

**Goal:** 在现有新闻采集和 SQLite 数据之上增加独立新闻中心、每日简报、搜索筛选和重大新闻排序。

**Architecture:** 后端新增聚合服务和路由，查询机会中心已有新闻、匹配和影响分析；前端新增独立页面与左侧入口。所有改动使用测试驱动并保留现有恒生科技新闻功能。

## Tasks

1. 为 `OpportunityStore` 增加新闻中心结构化查询和日期列表，并以存储测试验证筛选与排序。
2. 新建 `news_center` 模型与服务，生成可追溯的每日简报和重大新闻列表。
3. 新建 FastAPI 路由，提供文章、日期、简报和刷新接口，并验证查询参数。
4. 扩展前端 API，新增 `NewsCenter.tsx`、路由和侧边栏入口。
5. 增加前端交互测试，运行后端测试、前端构建和浏览器验收。
6. 更新产品日志并提交。
